# Dokumentasi Teknis - Sistem Akuisisi Fotogrametri Otomatis Berbasis UR5

Folder ini berisi dokumentasi teknis Bahasa Indonesia untuk proyek UR5 Photogrammetry.

## Isi Folder

- `main.tex`  
  Source LaTeX dokumentasi teknis.

- `dokumentasi_fotogrametri_ur5.pdf`  
  Hasil compile PDF dokumentasi teknis.

- `webodm_quality_report.pdf`  
  Laporan kualitas hasil rekonstruksi dari WebODM.

- `figures/`  
  Kumpulan gambar evidence proyek, termasuk setup hardware, UI, terminal capture, dataset, hasil WebODM, dan quality report.

## Ringkasan

Dokumentasi ini menjelaskan pipeline akuisisi citra otomatis menggunakan robot arm UR5, webcam NEMESIS, relay/input board, camera interface berbasis C++/OpenCV, backend Bun/Elysia, user interface web, dan WebODM untuk rekonstruksi 3D.
